# 同传翻译 Android 1.1.1

安卓独立版本 v1.1.1（versionCode 3），支持 Android 10 及以上。本次更新由真机使用反馈驱动：v1.1.0 的悬浮字幕同时显示原文和译文，长句会占掉半屏以上。

悬浮字幕改为纯译文滚动字幕（参考 YouTube / ViiTor 的视频字幕）：

- 只显示译文，不显示原文；原文仍可在应用内同传页、历史会话记录和导出文本中查看。
- 最多 3 行：已完成译文（绿色加粗）在前、实时译文（浅色非加粗）占最后一行，合计取最新 3 行；新译文在底部，旧译文向上滚动。
- 行数超限时框内滚动、滚动条隐藏，字幕框限制在约 3 行高度，窗口整体远小于半屏。
- 双向模式两个通道的译文同时显示，前缀为「收听｜」「发言｜」；标题第二行显示正在翻译 / 正在连接 / 重连中 / 已静音。
- 保留拖动标题移动、A− / A+ 字号（16–30）、收起/展开、隐藏后从通知「显示字幕」恢复、位置记忆与横屏适配。
- 设置页移除「悬浮窗同时显示原文」开关，旧版本保存的该偏好不再读取。

本版修复：

- 标题状态：网络退避后的「正在重连 · 第 N 次」现在显示「重连中」，不再误显示「正在翻译」。
- 收起状态：窗口被系统摘除后自动重建时，按钮文案与内容状态保持一致。
- 完成/实时去重：已完成译文与尚未清掉的同句实时译文不再重复显示一行。
- 长句限框：100+ 字长句仍被限制在约 3 行框内，窗口不会撑到半屏；补充空内容高度、长句限框与重连后实时行注入测试。
- 长句滚动：整句一次性到达时，字幕框会在布局完成后自动滚到最新一行（句尾可见），不会停在长句开头。
