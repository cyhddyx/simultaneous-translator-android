# 同传翻译 Android 1.0.0

首个安卓独立版本，支持 Android 10 及以上。

包含麦克风/手机声音/双向同传、实时双语字幕、译文语音、音色配置、断线重连、后台通知、加密密钥和本地历史导出。安装后在设置中填入对应服务商的 API Key 即可开始配置使用。

此 APK 已签名，可侧载安装。19 项 JVM 测试、5 项 Android 15 模拟器测试通过。云端翻译、实体手机系统声音采集与长期后台运行仍需真实环境验证。安卓不支持向其他应用注入虚拟麦克风音频。
